# Contribution art architecture

## Stack and commands

Bun runs dependency-free JavaScript. Git stores empty commits as pixels; no
package install, OAuth application, external painter, or service is required.

```sh
bun run preview
bun test
python -m http.server 8765 --bind 127.0.0.1
# Open http://127.0.0.1:8765/art/preview.html
```

No build or production web deployment is needed; SVG and HTML are standalone.
To create an unpublished run, start from the tooling commit on the art branch,
set a Git identity already attributed to your GitHub account, then run:

```sh
bun index.js generate
bun index.js verify
```

Generation requires a clean checkout on `codex/rudy-contribution-art`, the exact
Radishoux/business origin, and no existing commits with this art ID in any local
branch. It refuses duplicate generation. A completed clone can still preview.

Initially push only the tooling commit and make the art branch default using
GitHub CLI. Then `bun index.js publish` sends fast-forward batches of at most
500 commits, resuming from the remote tip. It never force-pushes, deletes
branches, or changes the default itself.

## Files and module dependencies

- `index.js`: glyphs, validated plan, SVG/HTML preview, Git generator and publisher.
- `index.test.js`: calendar orientation, date boundaries, future-date guard, and preview mapping.
- `art/plan.json`, `art/rudy-code.svg`, `art/preview.html`: generated by preview.
- `.git/art-run.json`: local publication state (base, tip, branch, count); never uploaded.
- `.git/calendar-before.json`: optional local GraphQL snapshot; never uploaded.

Dependency direction: tests -> index.js -> Bun standard-library APIs -> Git.
The preview uses no network assets or imported modules.

## Data model and invariants

A plan has an ID, Sunday start, width, branch, disclosure, total, and ordered
`{date, count, glyph, x, y}` pixels. x counts weeks; y counts days from Sunday.
The date formula is `start + 7*x + y`. Only lit pixels receive commits. Every lit pixel receives 40 commits. Dates must be unique and past.

Author and committer dates are equal at noon UTC plus a few seconds, avoiding
DST shifts. Every commit explicitly says decorative art. All share the tooling
commit's file tree. Attribution was checked against the original public commit's
GitHub author login. Only the default art branch counts toward the profile.
GitHub chooses color thresholds; local preview shades are estimates.

## End-to-end flow

R's upper-left pixel is week 6, Sunday: 2026-02-15. The plan assigns 40 commits.
Preview emits a green cell with a date/count tooltip. Generation feeds Git
fast-import a linear chain of empty commits. Verification checks every day's
count, both timestamps, total, and tree equality. Publication pushes at most
500 new commits at once. GitHub indexes them under the associated account.

## Decisions and recovery (2026-10-07)

Original master: `99a624f93f0584dbb7f5c5ddefaed0c0b47f2fc0`. Its 30,500 generated
gitfiti commits followed `2e511fea512ae2b5d5e94b24e0721918c53b7dc6`. The live
calendar showed only the final 1,000 artwork commits. This is an observation,
not a documented indexing limit. Smaller pushes allow incremental verification.
A huge single push was rejected because the earlier result was incomplete;
force-replacing master was rejected because all old history can be retained.

The art branch starts at `2e511fea512ae2b5d5e94b24e0721918c53b7dc6`, preserving
earlier history. Master stays untouched. Restore the former default with:

```sh
gh repo edit Radishoux/business --default-branch master
```

GitHub documents up to 24 hours for contribution changes. Do not generate
duplicate art to trigger indexing. Compare actual date counts after switching;
old-art removal and new-art indexing can be delayed independently.

## Gotchas

- January 4 is Sunday; transposing axes destroys the design.
- Use Bun, not the old dependency-based randomized simulator.
- Master's old design is excluded from the new default branch but may remain
  temporarily in cached contribution counts.
- The optional preview baseline subtracts the 1,000 old pixels observed as indexed;
  it does not guarantee GitHub's final colors.
- The rolling year crops the art after January 2027; select 2026 to retain it.
- If `.git/art-run.json` is lost, recover its base from the tooling commit and
  its tip from the final art commit. Never guess the base or skip verification.
